# Códigos MATLAB

En esta carpeta se encuentran los códigos desarrollados en MATLAB durante el Laboratorio de Análisis de Señales.

Los programas permiten realizar el análisis, procesamiento y representación de las diferentes señales estudiadas durante la práctica, incluyendo el desarrollo teórico y experimental según corresponda.

En total, esta carpeta contiene los diferentes códigos utilizados para obtener y analizar los resultados presentados en el informe final del laboratorio.

## Contenido

Los archivos `.m` incluidos corresponden a los diferentes ejercicios, análisis y procedimientos realizados durante el laboratorio.

Cada código puede ejecutarse en MATLAB para reproducir los cálculos, análisis y gráficas correspondientes.

## Herramienta utilizada

- MATLAB
