# Laboratorio de Análisis de Señales

## Descripción

Este repositorio contiene el desarrollo del Laboratorio de Análisis de Señales realizado en la asignatura de Procesamiento de Señales. Aquí se incluyen los códigos desarrollados en MATLAB y el informe final, en el cual se presenta el procedimiento, análisis y resultados obtenidos durante la práctica.

## Objetivo

Analizar y procesar diferentes señales mediante herramientas computacionales, realizando comparaciones y estudios de los resultados obtenidos durante el desarrollo del laboratorio.

## Organización del repositorio

### 📁 Codigos matlab

Contiene los códigos desarrollados en MATLAB para realizar los diferentes ejercicios, análisis, procesamiento y representación de las señales estudiadas durante el laboratorio.

### 📁 Informe

Contiene el informe final del laboratorio, donde se presenta la metodología, el desarrollo de las actividades, los resultados obtenidos y las conclusiones.
